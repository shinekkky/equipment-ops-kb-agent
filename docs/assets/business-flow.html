PRODUCT WORKFLOW / 产品业务流程

从设备数据到可执行处置：一条完整的运维诊断链路

数据接入 → 异常监测 → 知识检索 → Agent 诊断 → 诊断报告，每一步都有明确的输入与交付物。

更早发现风险
每条结论有据可查
处置可排期执行
01
DATA INGESTION

设备运行数据接入

接入温度、振动、电流、转速、运行状态等时序数据，并关联设备台账与控制系统故障代码。

输出　标准化时序数据 + 设备台账
02
RISK DETECTION

异常监测与风险预警

四层检测识别已越限、短时突变、缓慢劣化与多参数联合偏移，输出风险等级、证据链与提前量。

输出　异常结论 + 风险分级
03
KNOWLEDGE RETRIEVAL

知识库检索与故障诊断

从设备手册、故障知识与历史依据中检索对应章节，给出可回溯的原文出处与处置步骤。

输出　命中章节 + 手册依据
04
AGENT DIAGNOSIS

Agent 调用诊断工具

模型通过工具获取真实设备数据与手册内容，完成异常定位、原因分析与处置建议生成，数字不靠估算。

输出　带工具轨迹的诊断答复
05
ACTIONABLE REPORT

运维诊断报告

汇总异常证据、手册依据与P0–P3 处置排期，形成可交接、可审计、可导出的诊断报告。

输出　Markdown / PDF 报告
一条结论贯穿“数据 → 判断 → 依据 → 建议 → 行动”，避免监测与处置脱节
数据 风险 知识 诊断 行动
